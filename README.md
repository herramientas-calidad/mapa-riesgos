# Mapa de Riesgos · Procesos sanitarios

Aplicación web: **https://herramientas-calidad.github.io/mapa-riesgos/** (versión 2026.11).

Aplicación web (PWA) estática, sin dependencias, que funciona sin conexión y se puede instalar en el móvil, para elaborar **paso a paso** el mapa de riesgos de cualquier proceso sanitario:
- el proceso y sus subprocesos;
- el flujograma, que la app dibuja sola;
- los puntos críticos;
- el análisis AMFE y las acciones de mejora;
- el mapa: el flujograma con los riesgos encima, coloreados por su IPR;
- el documento final.

Los 10 pasos, del proceso al Documento Final en Word y PDF, con la lámina del mapa, el modo presentación y un archivo con los riesgos clave para una auditoría. Para aprender: temas explicados fácil, las 30 preguntas del test del curso (con test inicial y final), ejercicios, el caso clínico y cinco minicasos con un error para encontrar.

Lleva dentro, en la carpeta `motores/`, los motores de cálculo y de dibujo de AMFE y de Flujograma. Con «Cargar archivo de…» importa la copia de seguridad (.json) de las apps Flujograma, AMFE, DAFO · CAME, Rondas de Seguridad e Indicadores.

Los datos se guardan solo en el dispositivo. Herramienta docente y de apoyo: no sustituye el criterio profesional.

Forma parte de un conjunto de herramientas de calidad y seguridad del paciente. Si quieres conocer las demás, pide información a sus autores.
